# USB CDC コンソール (BT非連動・モード固定) 設計メモ

承認済み案A。無線モード (W 0) で Pico の USB を PC に挿し、
UART アダプタなしでログ・操作コマンドを使うための機能。

## 目標

- W 0 の Pico USB を PC に挿すと USB シリアル (COM ポート) として認識され、
  UART と対等のコンソールになる。UART アダプタを不要にする。
- W 1 (有線) の USB は純粋 HID のまま1バイトも変えない (Switch 互換の維持)。

## 構成方針

- 新規 `src/usb_cdc.c/.h` に TinyUSB CDC 駆動を閉じ込める。
  `pico_enable_stdio_usb` は OFF のままにする (USB 乗っ取り防止のため
  `pico_stdio_usb` は使わず、TinyUSB の CDC を自前駆動する)。
- `src/usb_descriptors.c` はモード別に2種の構成記述子を返す。
  W 0: HID+CDC 複合。W 1: 純粋 HID (現行バイト列と同一)。
- `src/ui.c` の行組立は発信元タグ付き (UART/CDC) の純粋関数に切り出す。
  `W` コマンドはタグが UART の行だけ実行し、CDC 発は拒否行で返す。
  依存方向は現行のまま (`ui → usb_cdc` の一方向追加のみ)。
- `cap` / `util` / `usb_hid` は Pico・BTstack 非依存のままにする。

## データフロー

- 受信: UART 蓄積と CDC 受信 (`tud_cdc_read`) をそれぞれ行バッファに溜め、
  完成行に発信元タグを付けて投入する。`W` 以外は両方から実行可
  (共有の入力状態への後勝ち。単一スレッドのため競合なし)。
  `W` の CDC 発は既存流儀の `usage:` 形式行で拒否し、状態を変えない。
- 送信: `probe_line` は UART (現行通り) に加え、CDC マウント中は CDC にも
  出す (`tud_cdc_write`＋flush)。

## モード遷移

- 起動時: 保存 W 値で記述子セットを決定する (W 0＝複合、W 1＝純HID)。
  BT リンク状態は無関係。
- `W` 切替時: 保存→記述子セット切替→再列挙する。PC 側には COM ポートの
  抜き挿しに見える。W 1＋ドックの動作は現行と同一。
- W 0＋ドックの組み合わせでは Switch は複合機器を見てプロコン認識しない
  (無害・想定内)。
- BT 動作・無線デフォルト・`st` 等のログ書式は変えない。

## 境界条件

- CDC 抜線時は行途中を破棄する (次回接続に持ち越さない)。
- CDC 未マウント時の送信はスキップし、ブロックしない。
- `usb ...` 行の末尾に `cdc=` 表示を追加する (付加のみ)。
- 秘密 (LTK/IRK/AES 鍵) をログに出さない。
- CDC バッファは固定長 (`LINE_MAX` 流儀) で、溢れは切り捨て＋カウンタ。
- W 1 中は CDC が記述子に存在しないため PC からも見えない (仕様)。

## 検証

- ホスト単体テスト: 行組立・発信元タグ・`W` ゲートの純粋関数を TDD で
  追加する。TinyUSB/BTstack 依存部は対象外 (従来通り)。
- 実機: (1) PC＋W 0 で COM 列挙と全コマンド疎通 (`W` は拒否されること)。
  (2) Switch ドック＋W 1 の回帰 (認識・入力・色は従来通り)。
  (3) `W` 往復と起動時復元。(4) UART 併用時の二重コンソール動作。
